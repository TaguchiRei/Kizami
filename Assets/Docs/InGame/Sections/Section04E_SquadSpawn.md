# 区間4E：スポーン位置と編成

| 項目 | 内容 |
|---|---|
| 状態 | 未着手（着手前にこの計画を見直す） |
| 目安の時期 | 2027/02/09〜02/15（最速の推定 2026/10/11〜10/12） |
| 前提となる区間 | 9 |
| 全体計画 | [InGameOverallPlan.md](../InGameOverallPlan.md) |

区間の番号は識別用。区間4E は 2026-10-10 に追加した区間で、区間9のあと、区間4F の前に行う。

## 目的

敵のスポーンを「スポーン位置 1 つにつき 1 グループ」にする。

- スポーン位置ごとに、属する区画と、出すグループの編成（ScriptableObject）を指定する
- 初期生成の範囲と、間隔での生成をなくす
- ほかのグループとの合流をなくす
- 区画とスポーン位置を、シーンビューで見て選べるようにする

撤退・補充・全滅後の出し直しは区間4G で作る。この区間では、開始時に出したグループが減っていくだけになる。

## 既存の資産

| 資産 | 内容 |
|---|---|
| `EnemySpawnSystem` | ステージシーンの生成の設定。同時に存在する数の上限、生成情報（`EnemySpawnInfo`）、格子の範囲、区画の大きさ |
| `EnemySpawnPoint` | 実行中の生成位置。半径、有効か |
| `EnemyInitialSpawnArea` | 初期生成の範囲。数と編成 |
| `EnemySpawnAdapter` | `SpawnInitial`、`SpawnByInterval`、`TrySpawn`、`TryGetNextSpawnPoint`、`ReturnStrandedAgents`（グループを持たない敵を次の生成位置へ移す） |
| `EnemyGroups` | `TryMerge`（合流）、`MaintainNext`（穴詰め・合流・並べ替え）、`EnemyFormationSettings.MergeSize` |
| `EnemyDistanceField` | 区画（範囲の中心が区画の中心）と追跡範囲。追跡範囲の Gizmo |
| Unity の機能 | `Gizmos.DrawIcon`（距離によらない大きさのアイコン。クリックで選べる）、スクリプトの `[Icon]` 属性 |

## 作業一覧

| # | 作業 | 層 | 内容 |
|---|---|---|---|
| 4E-1 | 合流をなくす | EngineAdapter | `TryMerge`、`MergeSize`、合流に関わる記述を消す |
| 4E-2 | 編成の ScriptableObject | External / EngineAdapter | グループの編成（`EnemyKind` の並び）を持つアセット |
| 4E-3 | スポーン位置の 1 グループ | EngineAdapter | スポーン位置に区画と編成を持たせる。開始時にスポーン位置ごとに 1 グループを出す。初期生成の範囲と生成情報を消す。グループを持たない敵の扱いを直す |
| 4E-4 | デバッグ表示 | EngineAdapter | 区画を色分けして描く。スポーン位置をアイコンで描き、遠くからクリックで選べるようにする |
| 4E-5 | TestStage の配置 | Level | `EnemySpawnSystem_Few` と `EnemySpawnSystem_Crowd` を、スポーン位置と編成の形に置き直す |

## 完了条件

- 開始時に、スポーン位置ごとに、指定した編成の 1 グループが出る。実行中に新しいグループは出ない
- 減ったグループがほかのグループへ合流しない
- 区間4D・9 の挙動（待機・追跡・帰還、外側と内側の螺旋、弾・バリア・吸収）を壊さない
- シーンビューで区画が色分けされ、スポーン位置のアイコンを遠くからクリックして選べる

## 詳細仕様で決めること

| # | 項目 | 案 |
|---|---|---|
| 1 | 区画の指定の仕方 | a. スポーン位置に区画の番号（x, z）を持たせる。b. 区画を表すオブジェクトを置き、その子にスポーン位置を置く |
| 2 | 指定した区画を何に使うか | 持ち場が追跡範囲に入っているかの判定（今は持ち場の位置で判定）を、指定した区画で行うか。位置と指定が食い違ったときの警告 |
| 3 | 同時に存在する数の上限 | `EnemySpawnSystem.MaxAliveCount` を残すか、スポーン位置の編成の人数の合計から決めるか |
| 4 | 編成のアセットの中身 | `EnemyKind` の並びだけか。人数（今は `EnemyFormationSettings.GroupSize` の 12）を編成ごとに持つか |
| 5 | グループを持たない敵 | グループの枠が足りないときにグループなしで出る経路（`TrySpawn` が `TryAdd` の結果を見ていない）と、`ReturnStrandedAgents` の「次の生成位置へ移す」を、どう扱うか |
| 6 | 区画の色分けの描き方 | 区画の範囲の床に半透明の面を描くか、枠だけか。追跡範囲の Gizmo と同じ切り替え（`_drawDistanceField`）にするか |

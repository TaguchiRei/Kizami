区間の番号は識別用。区間15は 2026-10-09 に追加した区間で、区間9のあと、区間10の前に行う。区間10のダメージタイプの表で、各攻撃の強さと減衰率を、装甲への効き方と一緒に決められるようにする為。

## 目的

マップに置く大きな建物（ビルなど）を、削れるボクセルにする。1 階分をベイクして縦に積み重ね、素材ごとの強度で壊れ方を変え、階の上下のつながりが断たれたら倒す。倒れていない建物の傷は、敵の追跡範囲の外に出たら修復し、戻ったら当て直す。

## 前提

- 今のボクセルは、データと分離の判定がボリューム全体を扱う。大きな建物を 1 つのボクセルにすると、削るたびに全体の点を調べる（[LargeObjectVoxel.md](../../Voxel/LargeObjectVoxel.md) の「今のボクセルの重さ」）
- 敵は建物に上れない。傷を残す範囲は、区間4D の追跡範囲と同じ

## 完了条件

- レンガの壁を弱い攻撃で削ると、目地が深く削れてレンガの形が浮き出る。鉄筋コンクリートの柱は、コンクリートが崩れたあとに鉄筋が残る
- 階の柱を断つと、上の階がまとめて倒れ、下の敵を巻き込む。倒れた建物は地形として残り、敵がそれを避けて動く
- 傷を付けた階は、追跡範囲の外へ離れるとメッシュに戻り、戻ると同じ傷が戻る
- 階をたくさん積んだ建物を削っても、削る 1 回の時間が建物の高さで増えない

## 既存コードの確認結果（2026-10-11）

計画書の前提と既存の資産は、今のコードと合っている。

| 対象 | 今の状態 | 15 での扱い |
|---|---|---|
| `VoxelVolume` | 点ごとに距離（`_samples`）と温度（`_temperatures`）だけを持つ | 15-2 で素材の番号（byte）を足し、`Clone`・`ExtractComponent`・`Resample` で一緒に扱う |
| `VoxelPiece.LateUpdate` → `Measure` | 削ったあとの LateUpdate で、ボリューム全体の点に塊の番号を振る | 15-1 でかかる時間を測る。15-3 で、分離の判定のあとに上下の面のつながりを見る |
| `VoxelPiece.Slice` | ボリュームを複製し、片側ずつ削る | 15-1 でかかる時間を測る |
| `VoxelPiece.LastRemeshMilliseconds` / `TriangleCount` | 再メッシュ化の時間と三角形の数を公開し、`VoxelDebugCarveTool` が画面に出す | 15-1 の計測で、同じ形で削る・分離の判定・切り分けの時間を足す |
| `VoxelDebugQualitySwitch` | Tab で品質設定を切り替えて読み込み直し、読み込みの時間を出す | 15-1 で 0.4m と 0.2m の切り替えに使う |

| 品質設定 | PC 0.03m、Mobile 0.05m、Terrain 0.2m | 0.4m の品質設定を足す |

## 作業計画（2026-10-11）

15-1 の計測の結果で、詳細仕様の #1（ボクセルの大きさ）と #4（模様のずらし方）が決まり、15-2 以降の作り方が変わる。そこで区間を 2 段階に分ける。

- 段階A：15-1 だけを行い、計測の結果を報告して止まる。#1 と #4 を決める
- 段階B：決まった値をもとに、15-2〜15-4 の作業計画を立て直す

### 段階A のコミットの分け方

| # | 内容 | 確かめ方 |
|---|---|---|
| A-1 | 計測用の 1 階分（40m × 40m × 高さ 4m。床・柱・窓のある外壁）を箱で組んだプレハブと、そのベイク、0.4m の品質設定、計測用のシーン | シーンに出て、0.4m と 0.2m を切り替えて削れる |
| A-2 | 削る・分離の判定・切り分けの時間を `VoxelPiece` に公開し、`VoxelDebugCarveTool` の画面に出す。点の数、メモリ、チャンクの数も出す | プレイモードで数値が出る |
| A-3 | オブジェクト空間の座標から模様を描く仮のシェーダー（Shader Graph と Custom Function の 3D ノイズ）と、階を 20 個並べた描画の計測。#4 の 3 案を比べる | Frame Debugger で SRP Batcher のまとまりを見て、フレーム時間を記録する |
| A-4 | 計測の結果をこの計画書と [LargeObjectVoxel.md](../../Voxel/LargeObjectVoxel.md) に書き、#1 と #4 の案を出す | ― |

### 新しく作る型

段階A では新しい型を作らない。計測は、既存の `VoxelPiece` の公開値と `Kizami.VoxelDebug` のデバッグ用コンポーネントを広げて行う。

### 計測の条件

- 計測はユーザーの今の PC のエディタで行う
- 低スペックの PC での計測は、全体計画を完走してビルドできる段階で行う

## 他プラットフォームへの対応

- 削った階はチャンクごとの MeshRenderer になり、描画の数とメモリが増える。スマホと VR での重さは、15-1 の計測の値を残しておき、区間13で確かめる。低スペックの PC での重さも、ビルドできる段階で同じく確かめる

## 目的

チャージを消費して時間を遅くするスローモードを作る。スロー中にかけらをつかみ、投げたりランチャーで撃ったりして、粉砕タイプのダメージを出せるようにする。

## 関連する仕様

- スローモード：https://app.notion.com/p/3e91ea2aa7fa81a3914be1ccc47b86aa
- つかみ・投擲・ランチャー：https://app.notion.com/p/3e91ea2aa7fa81c5b7bafeaf029b5f2d
- 時間制御（スローモード）：https://app.notion.com/p/3ea1ea2aa7fa8183bbfac10bfafd4d70

## 前提

- スローモードは、区間0の TimeScale State の倍率を `ITimeScaleController` で下げて実現する
- 世界全体（敵、かけら、オーブ、ボクセルの粒子、プレイヤーの物理）が遅くなる。プレイヤーのアニメーション、視点操作、UI は等速
- 区間3で、かけらは `FragmentOrbAdapter` が管理し、ぶつかるか寿命（3 秒）が来るとオーブになる（`Time.time` で数えるので、スロー中は寿命も遅く進む）。つかむかけらとオーブ化の関係、投擲・ランチャーのかけらを管理から外す方法（7-8）は、この区間で決める

## 作業一覧

| # | 作業 | 層 | 内容 |
|---|---|---|---|
| 7-1 | スローモードの制御 | Application / BlackBoard | 発動時の消費、継続中の消費、ゲージが 0 になったときの終了。倍率は `ITimeScaleController` で変える |
| 7-2 | 切断回数の上限 | Application | スロー中に切断できる回数の上限 |
| 7-3 | 等速で動くものの確認 | EngineAdapter | プレイヤーの Animator の UnscaledTime、視点操作、UI が等速のまま動くこと |
| 7-4 | つかむ | Application / EngineAdapter | スロー中に、敵のかけらだけをつかむ |
| 7-5 | 投げる | Application / EngineAdapter | つかんだかけらを投げる |
| 7-6 | ランチャー | Application / EngineAdapter | つかんだかけらを 1 発だけ装填し、撃つ。装填は基本的にスロー中だけ |
| 7-7 | 粉砕ダメージ | Application | 投げたかけらと撃ったかけらを、区間5の窓口に粉砕タイプとして通す。装甲以外にはダメージを与えない |
| 7-8 | チャージからの除外 | Application | 投げたかけらと撃ったかけらはチャージにしない（区間3の印を使う） |
| 7-9 | サウンドのスロー表現 | EngineAdapter | AudioMixer の pitch などを State から設定する（仮） |

## 完了条件

- スローモード中は世界全体が遅くなり、カクつかない。視点操作とプレイヤーの手の動きは等速
- スロー中に何度も切断でき、上限の回数で止まる
- かけらをつかんで投げる、ランチャーに装填して撃つ、ができる
- ゲージが 0 になるとスローモードが終わる

## 詳細仕様で決めること

- スローの倍率
- 発動時の消費量と、継続中の消費量
- 切断回数の上限
- スローモードを終える操作（トグルか、ゲージが尽きるまでか）
- つかむ対象の選び方（照準の先、一定範囲の中 など）
- 投げる軌道（まっすぐか、放物線か）と威力
- ランチャーをスローの外でも撃てるか

## 他プラットフォームへの対応

- VR では、実際に手でつかんで投げる操作にできる。つかむ・投げるの要求を Application で持ち、判定の違いは Adapter に閉じ込める

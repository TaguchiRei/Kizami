## 実装結果（2026-10-23）

### 決めたこと
- ヒットストップは入れない（ゲームが重く、切った瞬間に止めると処理落ちに見えるため）。いったん作ったが、ユーザーが削除した。
- 腕の動きは IK（Animation Rigging）ではなく、Animator の 2D ブレンドにする。IK は導入して外した。
- かけらをつかんで投げる機能と、ランチャーをオミットする。オーブと崩爆は残す。
- Brilliant Skill は、仕様が固まるまで `StageInitializer` のスイッチで無効にする。つかんで投げる文字の処理は残す。
- ウォールラン中に手を壁へ当てる案はやめて、カメラを壁から離れる側へ約 5° 傾ける。
- 短距離ワープはオミット。`PlayerMoveMode.Warping` は突進と飛びの移動モードとして残す。

### 作った主なもの
- 腕：`PlayerArmAdapter`、`PlayerArm.prefab`、`Assets/Art/Animation/Player/` の `Player.controller` とクリップ（Idle、Slash_LeftRight、Slash_RightLeft、Slash_UpperDown、Skill_SwordTechniques ほか）。
  - 通常攻撃：切断面の角度から `BlendX = -cos`、`BlendY = sin` を決め、3 つのクリップを混ぜる。実時間で動く。
  - スキル：`SkillData._armAnimation` の Trigger 名を、`SkillService` の発動時に引く。壊剣と砕剣に `Skill_SwordTechniques` を割り当て済み。突進は付けない。
  - `ArmModel.fbx` の Avatar を生成する設定に変えた。
- カメラの傾き：`StandardPlayerCameraAdapter` が `PlayerContactState` の壁の法線から `Lens.Dutch` を補間する。`PlayerCameraAdapterBase` に `OnBlackBoardReady` を足した。
- かけらの投擲の削除：`FragmentThrowService` と `FragmentThrowAdapter` を言葉専用に絞り、`FragmentContactReporter`、HUD のランチャー表示、`PlayerParameterData` のかけら用の値、キー割り当て一覧の `LoadLauncher` / `FireLauncher` を削除した。

### 完了条件の確認結果
- 通常攻撃の横切り（0°）と縦切り（90°）の再生：プレイモードで確認した。斜めの角度と、実際の入力からの再生は未確認。
- スキルのアニメーション：コンパイルのみ。再生はユーザーがプレイテストで確かめる。
- カメラの傾き：`Dutch` の符号を数値で確かめた。壁走り中の実際の傾きは未確認（逆なら `GetRollDirection` の符号を反転する）。
- 投擲の削除と Brilliant の無効化：コンパイルのみ。動作はユーザーがプレイテストで確かめる。

### 次の区間へ持ち越すこと
- 38-4 行動のエフェクト：斬撃の軌跡とスキル発動（VFX Graph）。軌跡の見た目と、スキル発動を共通にするか別々にするかは未決定。
- 38-5 SE：エフェクトと一緒に、区間36 の口で付ける。
- 中身が空のスキルのクリップを作り、スキルごとに `_armAnimation` を割り当てる（`Skill_1` の持ち主も未割り当て）。
- 強化の種類 `ExplosiveFragment` と、入力アセットの `LoadLauncher` / `FireLauncher` の整理。enum の番号と保存データを変えないため残してある。
- `Player.controller` に残る試作の状態（`Slash_Side` など）の整理。
- Notion の仕様書への反映（ヒットストップなし、短距離ワープ、かけらの投擲、Brilliant の一時無効化、カメラの傾き）。ユーザーが内容を確認してから行う。
- Brilliant Skill を再び有効にするとき、つかむ・投げる文字の処理が今の `FragmentThrowService`（言葉専用）で動くかを確かめる。

### 使い方
- スキルに腕のアニメーションを付ける：クリップと同名の Trigger を `Player.controller` に足し、Any State からの遷移と Idle へ戻る遷移を作る。スキルのアセットの `_armAnimation` に、その名前を入れる。
- Brilliant Skill を有効にする：ステージの `StageInitializer` の `_isBrilliantSkillEnabled` を ON にする。

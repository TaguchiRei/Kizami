## 既存の資産

- 音の素材：`Assets/LocalAssets/Sound/`（10 個。`.gitignore` で除外されている）。二次配布禁止のものを含むので、リポジトリ外へ出さない。クローンやクラウドのセッションには無いので、クリップが無くても動く作りにする。AI で生成した音に全部置き換える場合もある（2026-10-21 ユーザー）
- 音を鳴らすコードは、まだない（`AudioSource` を使うコードがない）
- 音量の設定：`OperationSettingService` と State が、マスター・BGM・SE の音量を保存・読み込みしている（アウトゲームの区間4）。実際の音への反映はまだ
- Unity の `AudioMixer`：音量のグループ分けは、これで足りる見込み

## 作業一覧

## 完了条件

- 各シーンで BGM が流れ、遷移で切り替わる
- 36-3 で挙げた出来事で SE が鳴る
- コンフィグの音量が、実際の音量に反映される

### ボス関連

| # | 項目 | メモ |
|---|---|---|
| 45-6 | 2 回目の直接戦闘が一瞬で終わることがある | 原因の調査から。段階が進む条件を確かめる |
| 45-7 | 2 回目の直接戦闘で足が上がったままになる | 原因の調査から。足踏みの途中で段階が変わったときの戻し方が怪しい（仮定。未確認） |
| 45-8 | 円の柵が重い | ボクセルの破壊を無効にして、プレイヤーへのダメージだけにする案 |
| 45-9 | ビームがまぶしすぎる | ビームの基本色を黒などにしてまぶしさを抑える案 |
| 45-10 | 塔投げの落ちる位置 | 今の `BossTowerThrow` は、プレイヤーの位置とその真下の地面を狙う。その為、プレイヤーが空中にいると空中に刺さり、ボスから離れていると、倒した塔がボスに当たらない。XZ だけを見て、ボスから一定の距離の場所に落とす |
| 45-11 | 攻撃の予兆 | 攻撃の前に「ピピッ」という音を鳴らし、攻撃部位を赤か黄色で点滅させる。SE は区間36 の仕組みで足す。点滅は、区間32 のダウン中のハイライト（`MaterialPropertyBlock` で色を足す）が先例 |
| 45-12 | 最後の核を壊すフェーズのクリア判定 | 核以外でも 1 か所壊したら、5 秒後にクリアを出す案 |

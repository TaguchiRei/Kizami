## 目的

アルファ版の最後の区間。ほかの子の区間で足したものがそろった状態で全ステージを通して遊び、負荷・値・不具合を整え、使っていないものを消して、アルファ版を完了させる。

## 既存の資産

- 親の計画書の「前提の変化」にある、33-1・33-5 の持ち越しの一覧（区間11・16・17・18・19 から）
- 親の計画書の「未実装の洗い出し」にある、条件付きの項目（区間21、14-8、区間31・32 の負荷の計測）
- HUD・リザルト・ポーズは `UiBuilder`（EngineAdapter）がコードで組んでいる

## 作業一覧

| # | 作業 | 内容 |
|---|---|---|
| 43-1 | 負荷の計測と調整（33-1） | 敵の数、かけらの数、ボクセルの作り直しが重なる場面で計測し、上限や品質設定を調整する。持ち越しの一覧（コライダーの上限、`VoxelPiece.Slice` の重さ、敵の処理時間、融解の表示の上限、区間17 の 1 回目の差し替えの重さ）を確かめる |
| 43-2 | パラメータの調整（33-4） | チャージ、スキル、敵、ステージの各値。装甲への効き方（区間10）、敵のダメージと編成（区間22）、最終フェーズの難しさ（区間32）、体力のダメージ量（区間31） |
| 43-3 | 不具合の修正（33-5） | 全ステージを通して遊び、見つかった不具合を直す。ポーズ中の失敗で時間の倍率が 0 のまま残る件（区間19）、区間17 の持ち越し（古い Rigidbody の組、くっつけた塊への攻撃の記録） |
| 43-4 | 条件付きの項目 | 43-1〜43-3 で問題が出たときだけ、区間21（広いマップの格子）、14-8（敵の設定のステージ別化）に着手する |
| 43-5 | 使っていないものの削除 | `CoreSystem` / `CorePart` の旧コード（区間31）、使われなくなったミサイルのアセット（区間32） |
| 43-6 | HUD の見た目（33-6） | HUD・リザルト・ポーズの画面をプレハブにし、`UiBuilder` を消す。HUD のスキルの枠で、どのスキルかが分かるようにする |
| 43-7 | ドキュメント | Voxel の説明ドキュメントへの追記（区間17 の持ち越し） |

## 完了条件

- 目標のフレームレートを、対象の PC スペックで保てる
- 全ステージを、アウトゲームから通して遊べる
- 43-3 で見つけた不具合が残っていない（残すものはユーザーが決め、理由を書く）
- `UiBuilder`、`CoreSystem` / `CorePart`、ミサイルのアセットがない

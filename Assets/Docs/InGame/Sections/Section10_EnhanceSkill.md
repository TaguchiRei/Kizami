|---|---|

## 目的

攻撃に別のダメージタイプを付けるなど、プレイヤーの能力を強化するスキルを作る。
切断に破壊属性を付けたときのために、厚みゼロの平面でボクセルを分ける操作を作る。

## 関連する仕様

- スキル：https://app.notion.com/p/3e91ea2aa7fa814ebd59e5038006aa39
- ダメージタイプ：https://app.notion.com/p/3e91ea2aa7fa81c49ddbf615308a48f8

## 前提

- ボクセルでできた物はメッシュ切断できない。切断攻撃に破壊属性を付けたときは、切断方向と同じ向きに、厚みゼロの平面でボクセルを分ける

## 既存の資産

| 資産 | 内容 |
|---|---|
| 区間5の成果 | ダメージタイプを複数持てるダメージのデータ |
| 区間6の成果 | スキルの定義データと発動 |
| ボクセルの編集 | 形状（球・箱・カプセル）で削る・盛る操作と、塊の分離（[Core.md](../../Voxel/Detailed/Core.md)、[Piece.md](../../Voxel/Detailed/Piece.md)）。平面で分ける操作はまだない |

## 作業一覧

| # | 作業 | 層 | 内容 |
|---|---|---|---|
| 10-1 | 強化型スキルの仕組み | Application / BlackBoard | 効果時間と、効果中の攻撃にダメージタイプなどを追加する仕組み |
| 10-2 | 切断に破壊属性を付ける | Application | 効果中の切断を、攻撃タイプと破壊タイプの両方を持つダメージにする |
| 10-3 | ボクセルを平面で分ける | EngineAdapter | 厚みゼロの平面でボクセルを分ける、新しいボクセルの操作 |
| 10-4 | 切断速度アップ | Application | 攻撃間隔を短くする |
| 10-5 | 投げたかけらの爆発 | Application / EngineAdapter | 投げたかけらが当たった場所で範囲ダメージを出す |

## 完了条件

- 強化型スキルが 2 種以上動く
- 破壊属性を付けた切断で、ボクセルが切断面に沿って分かれる

## 詳細仕様で決めること

- 強化型スキルの一覧と、それぞれの効果時間と消費量
- 平面で分ける範囲（切断の範囲の中だけか）
- 平面で分けたあと、細かい側の塊を分離して落とすか（既存の塊の分離に乗せるか）
- 爆発の範囲と、どのダメージタイプを持たせるか

## 他プラットフォームへの対応

- プラットフォームによる違いはない

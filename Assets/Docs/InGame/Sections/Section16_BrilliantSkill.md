## 目的

プレイヤーがよい行動をしたとき、その場の空間にボクセルの文字を出してほめ、追加スコアを入れる。よい行動をその場でほめて、気持ちよさを強める。

区間11で、Brilliant Skill は区間11とは別の区間で作ると決めた（区間11の決めたこと 13）。判定の条件の値は、本番のステージの敵の数や建物の大きさで決まるので、区間14のあとに置いた。

## 既存の資産

| クラス | 内容 |
|---|---|
| `StageFlowService` / `IStageFlowState` | 区間11で作ったインゲームの流れ。スコア ＝ 倒した数 ＋ クリアの基礎スコア。追加スコアを受け取る口はまだない（この区間で足す） |
| `EnemySpawnAdapter.SetOnDefeated` | 核で倒した敵と、崩落・圧死で倒した敵の数を通知する（区間11）。吸収された敵は通知しない |
| 建物の倒壊 | 区間15の `VoxelBuilding`。倒壊は `VoxelBuilding.RegisterOnCollapsed` で受け取れる（今は `EnemySpawnAdapter` が購読している）。「大きな構造物を崩す」の判定に使う |
| ボクセル | `VoxelModelLoader` / `VoxelPiece`。文字を作る手段があるかは、まだ確かめていない |

## 作業一覧

| # | 作業 | 層 | 内容 |
|---|---|---|---|
| 16-1 | よい行動の判定 | Application | 倒した数の通知や建物の倒壊から、よい行動を判定する。種類をあとから足せる形にする |
| 16-2 | 追加スコアの口 | Application / BlackBoard | `StageFlowService` に追加スコアを足し、リザルトのスコアに反映する |
| 16-3 | ボクセルの文字の表示 | EngineAdapter | 発生した場所の近くの空間に、ボクセルの文字を出す |
| 16-4 | 発生の演出 | EngineAdapter | 文字の出方と消え方。区間13のエフェクトとの分担を決める |

## 完了条件

- 決めたよい行動をすると、その場の空間にボクセルの文字が出る
- 発生するとスコアに追加スコアが入り、リザルトのスコアに反映される
- よい行動の種類を、あとから足せる

## 詳細仕様で決めること

- よい行動の種類と、それぞれの判定の条件（Notion の「検討中」）
- 文字の内容、出す位置、演出（Notion の「検討中」）
- 追加スコアの値（Notion の「検討中」）
- ボクセルの文字の作り方（文字ごとのボクセルのアセットを用意するか、実行時に作るか）

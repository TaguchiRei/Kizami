# 区間4G：撤退と補充

| 項目 | 内容 |
|---|---|
| 状態 | 未着手（着手前にこの計画を見直す） |
| 目安の時期 | 2027/03/02〜03/08（最速の推定 2026/10/17〜10/18） |
| 前提となる区間 | 4F |
| 全体計画 | [InGameOverallPlan.md](../InGameOverallPlan.md) |

区間の番号は識別用。区間4G は 2026-10-10 に追加した区間で、区間4F のあと、区間15の前に行う。

## 目的

減った部隊を撤退させて補充し、全滅した部隊を出し直す。

- 満員の人数の一定の割合（既定 60%）を失った移動中の部隊は、外側の螺旋の目標位置を手放して持ち場へ帰る
- 帰り終えたら減った分を持ち場に出し、合流させて満員に戻す
- 全滅したら、スポーン位置ごとの間隔のあとに満員の部隊を出し直す
- 帰還できずに臨時の拠点を持った部隊は、全滅するまで補充しない
- スポーン位置が壊されたら、そこからは出さない

## 作業一覧

| # | 作業 | 層 | 内容 |
|---|---|---|---|
| 4G-1 | 撤退 | Application / EngineAdapter | 撤退の割合の設定、撤退の状態、目標位置を手放す、持ち場へ帰る |
| 4G-2 | 補充 | Application / EngineAdapter | 帰り終えたら減った分（編成の欠けた種類）を持ち場に出し、同じ部隊に入れる。臨時の拠点では補充しない |
| 4G-3 | 全滅後の出し直し | Application / EngineAdapter | スポーン位置ごとの間隔、満員の部隊を出し直す |
| 4G-4 | スポーン位置の破壊 | EngineAdapter / Level | スポーン位置をボクセルにし、壊れたら出さない |

## 完了条件

- 60% を失った部隊が目標位置を手放して持ち場へ帰り、帰り終えると満員に戻って再び追う
- 全滅した部隊が、スポーン位置の間隔のあとに満員で出直す
- 臨時の拠点を持った部隊は補充されず、全滅したあとは出し直しの規則に従う
- スポーン位置を壊すと、そこからは出なくなる
- 区間4D・9 の挙動を壊さない

## 詳細仕様で決めること

| # | 項目 | 案 |
|---|---|---|
| 1 | 撤退の割合の置き場 | 「敵の全体の設定」を、`EnemySpawnAdapter` の Inspector にするか、External の ScriptableObject にするか。設定の名前を「撤退する損耗の割合（既定 60%）」にするか「撤退する残りの割合（既定 40%）」にするか |
| 2 | 撤退を判断する状態 | 「移動中のグループ」を、追跡中（着いて螺旋に並んでいる間も含む）とするか |
| 3 | 補充の出し方 | 欠けた種類を編成の順番で出し、持ち場で待たせずに同じ部隊の隊列の後ろに入れるか |
| 4 | 撤退中に全滅したとき | 全滅後の出し直しと同じに扱うか |
| 5 | 臨時の拠点の部隊が全滅したあと | 元のスポーン位置から、間隔のあとに出し直すか |
| 6 | スポーン位置が壊れたとみなす条件 | 破壊対象（`DestructionTarget`）の割合の仕組みを使うか |
| 7 | スポーン位置のボクセルのモデル | この区間で仮の形を作るか、区間14でステージと一緒に作るか |
| 8 | 補充で出す敵の見せ方 | プレイヤーに見える所で突然出ないようにするか（持ち場がカメラに映っているときの扱い） |

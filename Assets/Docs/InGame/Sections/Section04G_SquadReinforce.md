| 全体計画 | [InGameOverallPlan.md](../InGameOverallPlan.md) |

区間の番号は識別用。区間4G は 2026-10-10 に追加した区間で、区間4F のあと、区間15の前に行う。

## 目的

減った部隊を撤退させて補充し、全滅した部隊を出し直す。

- 満員の人数の一定の割合（既定 60%）を失った追跡中の部隊は、外側の螺旋の目標位置を手放して元のスポーン位置へ帰る
- 帰り着いたら減った分をスポーン位置に出し、合流させて満員に戻す
- 全滅したら、スポーン位置ごとの間隔のあとに満員の部隊を出し直す
- 帰還できずに臨時の拠点を持った部隊は、全滅するまで補充しない
- スポーン位置が壊されたら、そこからは出さない
- 動けなくした敵は倒した数に入れない。無力化だけして倒さないことで、補充させない戦略を取れるようにする

## 完了条件

- 60% を失った部隊が目標位置を手放して元のスポーン位置へ帰り、帰り着くと満員に戻って再び追う
- 全滅した部隊が、スポーン位置の間隔のあとに満員で出直す
- 臨時の拠点を持った部隊は撤退も補充もせず、全滅したあとは元のスポーン位置から出し直す
- 動けなくした敵は失った数に入らず、補充されない。動けない敵が残っている部隊は全滅とみなさない
- スポーン位置のキューブを 5% 削ると、そこからは補充も出し直しもしなくなる
- 区間4D・9 の挙動を壊さない
- 敵の処理が合計 4ms 以下（区間4B の決定 6）

## 既存コードの確認結果（2026-10-11）

| 対象 | 今の状態 | 4G での扱い |
|---|---|---|
| `EnemyGroups.OpenGroup`・`TryAdd`・`CloseGroup` | 新しいグループは空いている最初の番号を使う。編成に体の設定のある種類がないスポーン位置はグループを開かないので、以降の番号がずれる | 番号を指定してグループを開き、メンバーを足す形にする。部隊の番号 ＝ `_activeSpawnPoints` の番号に固定し、全滅した部隊を同じ番号で出し直せるようにする |
| `EnemyGroups.Compact` | 動けなくなった敵（壊れた移動部位が上限に達した敵）をグループから抜き、その場に残す | グループから抜けるのは倒れたときだけにする。動けない敵は隊列の後ろへ回し、動けるメンバーを前から詰める（動けない敵は歩かず、隊列の位置に穴が残る為。`EnemyMoveJob` は動けない敵を歩かせない） |
| `EnemySquadObservation.MemberCount` | 倒れたメンバーも、詰めるまで数える。詰めるのは 1 フレームに 1 グループ（`MaintainNext`） | 生きているメンバーの数にする。撤退の判定が部隊の数のフレームだけ遅れない為 |
| `EnemyGroup.BarrierHitCount` | グループに残り続け、最大耐久に達したらバリアを張らない | 補充で満員に戻したら 0 に戻す |
| `EnemySquadService` の持ち場 | 部隊が出たあとの最初の Step で、アンカーの位置を持ち場にする（`_hasHome`） | 観測のスポーン位置を持ち場にする。出し直しのときも同じ |
| `EnemyGroupJob.HasAliveMember` | 生きているメンバーがいなければグループを空ける | 動けない敵もメンバーに残るので、そのまま「倒されていない敵が残っている限り全滅しない」判定になる |
| `EnemyDistanceField` | 床を探すクエリは `_groundLayers` だけを見る | スポーン位置のキューブを別のレイヤーに置けば、格子はキューブがないものとして作られ、敵はキューブの中に出て歩いて出てこられる |
| 吸収（`EnemyFinisherAttack`） | 吸収した仲間は `IsAlive = false` にする | 倒れた敵と同じく失った数に入る |

## 詳細仕様で決めること

すべて決めた（2026-10-11、ユーザー）。

| # | 項目 | 決めたこと |
|---|---|---|
| 1 | 撤退の割合の置き場と名前 | `EnemyInitializer` の Inspector に「撤退する損耗の割合（既定 0.6）」を置き、`EnemySquadService.Initialize` へ渡す |
| 2 | 撤退を判断する状態 | 追跡中（置き場に着いて螺旋に並んでいる間も含む）だけで判断する |
| 3 | 補充の出し方 | 撤退すると判断した部隊が、元のスポーン位置に実際に帰り着いたときだけ、不足分を出す。普通の帰還では補充しない。欠けた種類を編成の順で出し、持ち場で待たせずに同じ部隊の隊列の後ろに入れる |
| 4 | 撤退中に全滅したとき | 全滅後の出し直しと同じに扱う |
| 5 | 臨時の拠点の部隊が全滅したあと | 元のスポーン位置から、間隔のあとに出し直す |
| 6 | スポーン位置が壊れたとみなす条件 | スポーン位置用のボクセルのオブジェクトが、読み込んだ時点の体積の一定の割合（既定 5%）以上を削られたら壊れたとみなす。割合は `EnemySpawnPoint` の Inspector に持つ。破壊対象（`DestructionTarget`）は使わず、クリアの判定にも数えない |
| 7 | スポーン位置のボクセルのモデル | ボクセルにしたただのキューブ。敵はキューブの内側から出てくる。キューブは専用のレイヤー（仮称 `EnemySpawn`）に置き、衝突の表は `Barrier` と同じにする（物理でぶつかるのは Player と Shard だけで、敵と崩落の塊は素通りする）。敵の経路の格子の床のレイヤーには入れない |
| 8 | 補充で出す敵の見せ方 | 見えていてもそのまま出す。出てくる演出は区間13へ持ち越す |
| 9 | 動けなくなった敵の扱い | グループから抜けずに残す。失った数に入れず、補充しない。グループに倒されていない敵が残っている限り全滅しない。撤退で部隊が帰るとき、動けない敵はその場に残る |
| 10 | 補充を受けられない部隊の撤退 | 臨時の拠点にいる部隊と、スポーン位置が壊れた部隊は撤退しない。帰り着いても補充されず、すぐ追跡に戻って撤退を繰り返す為 |
| 11 | 補充のときのバリア | 補充で満員に戻したら、`BarrierHitCount` を 0 に戻す |
| 12 | 出し直しの間隔 | `EnemySpawnPoint` ごとの設定。既定 30 秒（区間14で調整） |
| 13 | フィニッシャーが吸収した仲間 | 失った数に入れる |

## 目的

最終ステージにだけ登場するボスを作る。ボスは、ボクセルでできた「動く破壊対象」になる。

## 関連する仕様

- ボス：https://app.notion.com/p/3e91ea2aa7fa81cbb8c6cb10382ac972
- 破壊対象：https://app.notion.com/p/3e91ea2aa7fa81b2a6ecd57b9542b589

## 前提

- ボスは、ボクセルでできたパーツを、パーツ単位で FK / IK で動かす。ボクセルのスキニングは使わない

## 既存の資産

| 資産 | 内容 |
|---|---|
| [VoxelPiece](../../../Code/Scripts/EngineAdapterLayer/Voxel/Piece/VoxelPiece.cs) | パーツごとの Transform を持つ。`ApplyEdit` はワールド空間の形状でも削れる |
| 区間4A〜4C の成果 | 部位の役割（`EnemyPartRole` のサブクラス）、接続部側が残る切断、脚の 2 本の骨の IK（自前の計算、4C）。ボスにも部位の役割と IK を使うかは、この区間で決める |
| 区間11の成果 | ステージデータとインゲームの流れ。ボス戦は 4 つ目のステージ |
| 区間5の成果 | 破壊対象と、重要パーツによるクリア判定 |
| 区間8の成果 | 装甲 |

## 前提の変化（2026-10-07、区間5 の完了時）

- 区間5で、ボクセルのベイク（`VoxelModelBaker`）は、大きな三角形のメッシュだと中身が空になることが分かった（Unity の Cube を拡大したものでは、2m の立方体の中身がほぼ空）。面を 0.25m 程度に分けたメッシュなら正しく埋まる。最大距離は実行時のボクセル 2 つ分以上（0.6m）、余白は最大距離を覆う数（6）にする。ボスのパーツをボクセルにする前に、ベイクの側で直すかを決める（[Section05](Section05_DestructionTarget.md) の「見つけた問題」）

## 作業一覧

| # | 作業 | 層 | 内容 |
|---|---|---|---|
| 12-1 | ボスの構成 | Level / EngineAdapter | ボクセルのパーツを組み、FK / IK で動かす |
| 12-2 | 動く破壊対象 | Application | 区間5のクリア判定に、動く破壊対象として乗せる |
| 12-3 | 行動 | Application / EngineAdapter | 移動と攻撃のパターン |
| 12-4 | 装甲 | Level | 区間8の装甲を、ボスのパーツに付ける |
| 12-5 | 最終ステージ | Level / ExternalLayer | ボスが登場するステージのデータ |

## 完了条件

- ボスが動きながら攻撃してくる
- 装甲を壊してボスの重要パーツを削り切ると、クリアになる

## 詳細仕様で決めること

- ボスの形、行動、重要パーツ
- IK が必要か（必要なら Animation Rigging を入れる）
- 動いているパーツから分離した塊の扱い（その場で落とすか、パーツに付いたままにするか）
- 削られたパーツの動き方（重要パーツが削れると行動が変わる など）

## 他プラットフォームへの対応

- ボスの大きさと画角の関係は、VR ではとくに迫力に影響する。VR に対応するときに見え方を確認する

## 目的

破壊対象に体力を持たせる。体力が尽きるまで、その対象はボクセルの破壊も切断も受けない。体力は画面上部にゲージで出す。崩壊ステージの対象をこの形にし、殲滅ステージに撃破数の条件を足す。ボス（区間23）も同じ仕組みに載せる。

## 関連する仕様

- 破壊対象：https://app.notion.com/p/3e91ea2aa7fa81b2a6ecd57b9542b589
- ステージ（殲滅・崩壊）：Notion のメインシナリオ

## 確定した仕様（2026-10-19、ユーザー）

| # | 内容 |
|---|---|
| 1 | 体力制の対象は、体力が尽きるまでメッシュ切断もボクセル破壊も受けない。体力は画面上部に出す |
| 2 | 崩壊の対象はボクセルにし、形は半球にする。今の通常のオブジェクトのコアシステム（部位がボクセル片に当たると分離）を置き換える |
| 3 | 崩壊の対象の体力は、倒壊の巻き込みで大きく減る。通常攻撃やスキルでも減るが、巻き込みとの差を大きく付ける |
| 4 | 崩壊の対象の体力が尽きると、ボクセルの破壊が効くようになる。通常攻撃も、この対象だけはゼロ厚の切り分けで疑似的に切れる（区間20の印を使う） |
| 5 | 殲滅のクリア条件に「敵を N 体以上倒す」を足す。N は仮に 50 |
| 6 | 到達は変えない |

## 作業一覧

| # | 作業 | 層 | 内容 |
|---|---|---|---|
| 22-1 | 体力の持ち方 | Application / BlackBoard | 対象ごとの体力・最大値・状態（通常、無敵、減っていく）を Application が持ち、State で公開する |
| 22-2 | ダメージの入口 | EngineAdapter | 保護されたピースに当たった通常攻撃・スキル・落ちる塊を、体力のダメージとして報告する。ダメージの種類ごとに倍率を持つ |

| 22-5 | 崩壊の対象 | Level / EngineAdapter | 半球のボクセルの対象を作り、崩壊ステージのコアシステムと置き換える。倒す物の配置を合わせ直す |
| 22-6 | 殲滅の撃破数 | External / Application / EngineAdapter | `StageData` に必要撃破数（0 なら条件なし）を足し、`StageFlowService` で判定する。HUD に「撃破数 / 必要数」を出す |

## 完了条件

- 崩壊ステージで、対象の体力が上部に出る。倒壊に巻き込むと大きく減り、通常攻撃やスキルでは少しだけ減る
- 体力が尽きるまで、対象は削れも切れもしない。尽きたあとは、スキルで削れ、通常攻撃でゼロ厚の切り分けができる
- 対象を必要な割合まで壊すとクリアになる
- 殲滅ステージで、生産施設をすべて壊しても、50 体倒すまでクリアにならない。撃破数が HUD に出る

## 詳細仕様で決めること

| # | 項目 | 案 |
|---|---|---|
| 1 | ダメージの量 | 巻き込み 1 に対して、それ以外 0.1（仮）。巻き込みは塊の体積に比例させる |
| 2 | 体力の持ち主の層 | ボスの段階を Application（`BossBattleService`）が持つのに合わせ、体力も Application が持つ。EngineAdapter はダメージを報告する（直接の配線） |
| 3 | 1 つの攻撃で何回減らすか | 1 回の振り・1 回の発動で 1 回。ピースの数では数えない |
| 4 | 半球の対象の大きさと素材 | ステージに合わせて決める。モデルはベイクした半球 |
| 5 | 崩壊のクリア条件 | 体力が尽きたあと、重要パーツを必要な割合まで壊す（今の `DestructionTarget` の割合） |
| 6 | 撃破数の表示 | 必要撃破数のあるステージだけ出す |

## 目的

切断で生まれたかけらをオーブに変えてプレイヤーに吸収させ、チャージを溜める。

## 関連する仕様

- チャージ（かけら・オーブ）：https://app.notion.com/p/3e91ea2aa7fa81249000ca51326add0f

## 既存の資産

| 資産 | 内容 |
|---|---|
| 区間2の成果 | かけらの通知 |
| `MeshCutObjectPool` | かけらのプール。固定長のリングバッファで、生成数を超えると最も古いかけらを回収して使い回す。そのため、かけらの数は生成数を超えない。回収されたかけらでは `CuttableObject.ReuseAction` が呼ばれる |
| `CuttableObject` | かけらの本体。`Rigidbody`（`Rig`）と、実行時に作られる球コライダーを持つ |

## 作業一覧

| # | 作業 | 層 | 内容 |
|---|---|---|---|
| 3-1 | かけらの管理 | Application / BlackBoard | 切断で生まれたかけらを登録し、状態（飛んでいる・オーブ・吸収済み）を持つ。チャージにならないかけら（投げたかけらなど）の印を持てるようにする |
| 3-2 | オーブ化 | EngineAdapter | かけらが何かのコライダーに触れたらオーブにする。かけらはプールに返し、代わりにオーブを出す |
| 3-3 | 吸収 | EngineAdapter | オーブをプレイヤーへ引き寄せ、届いたら吸収済みにする |
| 3-4 | チャージの State | BlackBoard / Application | チャージ量の State と、加算と消費の操作。消費はスキル（区間6）とスローモード（区間7）が使う |
| 3-5 | ステージの外周 | Level | ステージ全体を囲うコライダー。下側は二重にするか、範囲外を判定する専用の Trigger を置く |
| 3-6 | オーブのプールと、かけらの強制回収 | EngineAdapter | オーブは `ObjectPool<T>` で使い回し、同時に存在する数に上限を設ける。かけらがプールに強制回収されたとき（`ReuseAction`）、管理の一覧から外す |
| 3-7 | デバッグ表示 | Debug | チャージ量の表示（`DebugGUI.ObserveVariable`） |

## 完了条件

- ダミーの敵を切ると、かけらがオーブになってプレイヤーに吸収され、チャージが増える
- 大量に切っても、かけらとオーブの数が上限を超えず、強制回収されたかけらが管理に残らない
- かけらがステージの外へ落ちない

## 詳細仕様で決めること

- かけら 1 個をチャージいくつにするか、ゲージの上限
- かけらをもう一度切ったときの数え方（最終的にオーブになったかけらの数で数える など）
- 何にも触れないかけらを、いつまでにオーブにするか
- 吸収の速さと、引き寄せ始める距離
- かけらのプールの生成数。強制回収されたかけらをチャージにするか（回収の直前にオーブにする、捨てる など）
- スロー中につかめるかけら（区間7）と、オーブになる前のかけらの関係

## 他プラットフォームへの対応

- プラットフォームによる違いはない。スマホでは、かけらの上限（プールの生成数）を別の値にする可能性がある

# 必要な SE の一覧

| 項目 | 内容 |
|---|---|
| 状態 | 洗い出し済み（2026-10-24）。音の生成と実装は未着手 |
| 関連する区間 | [区間36 SE と BGM](Sections/Section36_Sound.md)（音の土台）、[区間39](Sections/Section39_EnemyVisual.md)（39-6 は、洗い出しだけを行い、生成と実装は後ほど） |
| 使い方 | AI で音を生成するときの元にする。生成した音は、`SoundPlayer` の口（`SoundEffectKind` とクリップの配列）へつなぐ |

## 方針

- ここに挙げた音は、コードに該当する処理がまだ無いものも含めて、**必ず入れる**（2026-10-24、ユーザー）。「鳴らす場所」が「口を作る」のものは、実装のときに処理の口から作る
- 音の生成は、区間 39 の後ほど、AI で行いながら進める
- 鳴らす場所は、今のコードを読んで見つけた候補。メソッド名まで書いてあるものは、位置を確認済み。実装のときに、もう一度確認する
- 長さと種類は、生成のときの目安（仮）。種類は、短い音（ワンショット）、ループ（鳴らし続ける）、予兆（攻撃の前に鳴らす）に分ける

## 今ある音（作らない）

ガラスが割れる、装甲を切る（命中のたびに鳴る）、ボクセルを攻撃した、ボクセルが崩れる、BGM。

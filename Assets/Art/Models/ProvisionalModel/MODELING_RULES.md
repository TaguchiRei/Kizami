# ステージ用仮モデルの規約

[StageModelOrder.md](../../../Docs/InGame/StageModelOrder.md) の発注書に沿って、ボクセル化の元になる仮モデルを Blender Python で作る。寸法と素材の決まりは発注書の 2 章と 4 章を正本とし、ここには作るときの決まりだけを書く。

## 置き場所

| 物 | 場所 |
|---|---|
| FBX | このフォルダの直下。`<モデル名>.fbx` |
| `.blend` | `Blender~/`。Unity が取り込まないよう `~` 付きのフォルダに置く |
| 生成スクリプト | `Scripts~/`。共通処理は `kizami_model.py`、モデルごとに `build_<モデル名>.py` |

## 寸法

| 項目 | 値 |
|---|---|
| グリッド | 0.4 m。寸法と位置はすべてその倍数 |
| 厚み・隙間 | 0.4 m 以上 |
| 階の高さ | 4 m |
| 壁の厚さ | 内側に鉄筋を通す壁は 1.2 m（表 0.4 / 鉄筋 0.4 / 裏 0.4） |

## 形の作り方

- 0.4 m のセルの 3 次元の格子に素材を割り当て、素材ごとに、そのセルの集まりの外面を 1 つのメッシュにする。閉じたメッシュで、面は外向き
- 素材の違うメッシュは面で接するだけで、重ならない
- 壁の内側の層には `Rebar` を通す。ボクセル化で硬い部分として扱う為。表面から 0.4 m 以上内側に置き、外から見えないようにする。突き出した鉄筋だけは外に出る

## 軸・原点・階層

| 項目 | 値 |
|---|---|
| Blender での軸 | Z が上。壁の幅は X、厚さは Y |
| 書き出し | FBX。`axis_up='Y'`、`axis_forward='-Z'`、`bake_space_transform=True` で Unity の Y 上・前方 +Z にする |
| 原点 | 底面の中心（Z=0 が接地面） |
| 階層 | ルートの空オブジェクト `<モデル名>` の下に、素材ごとのメッシュ `<モデル名>_<素材>` を置く。子の原点はルートと同じ |

## 名前

- モデル名は `Stage_<区分>_<名前>_<番号>`。番号は 2 桁
- マテリアルは発注書 4.1 のスロット名（`Brick` / `Mortar` / `Concrete` / `Rebar` / `Metal` / `Wood` / `Glass`）。1 メッシュ 1 スロット

## 確認すること

- 寸法と各頂点の座標が 0.4 m の倍数
- 素材ごとのメッシュが閉じている（境界の辺がない）
- 斜め俯瞰と正面の 2 方向から Workbench で撮って形を見る

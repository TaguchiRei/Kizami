# ステージ用仮モデルの規約

[StageModelOrder.md](../../../Docs/InGame/StageModelOrder.md) の発注書に沿って、ボクセル化の元になる仮モデルを Blender Python で作る。寸法と素材の決まりは発注書の 2 章と 4 章を正本とし、ここには作るときの決まりだけを書く。

## 置き場所

| 物 | 場所 |
|---|---|
| FBX | このフォルダの直下。`<モデル名>.fbx` |
| `.blend` | `Blender~/`。Unity が取り込まないよう `~` 付きのフォルダに置く |
| 生成スクリプト | `Scripts~/`。共通処理は `kizami_model.py`、モデルごとに `build_<モデル名>.py` |

## マップ用モデル

インゲームのマップ（半径 350 m の円形）に置くモデルも、この規約に従って作る。

| 項目 | 決まり |
|---|---|
| 置き場所 | FBX は `Assets/Art/Models/Stage/` の直下。`.blend` と生成スクリプトは上の表と同じく、このフォルダの `Blender~/` と `Scripts~/` に置く |
| 建物 | 建設途中の建物。ボクセル化するので、寸法・厚み・素材はこの規約どおりに作る |
| 階の分け方 | 建物は `VoxelBuilding` で積むので、形の違う階ごとに別のモデルにする。名前は `<モデル名>_<階の種類>_01`（例：`Ground` / `Middle` / `Roof`、段差のある建物は `Tier28` など）。一番上の階以外は高さ 4 m にする |
| ガラス | ボクセルにせず、Unity で `GlassPane` の板を置く。生成スクリプトでは `Glass` の箱で窓を描き、`kizami_model.extract_glass` で抜き出して、板の配置を FBX の隣の `<モデル名>_Glass.json`（Unity の座標）に書き出す。板の元のモデルは `Stage_Glass_Pane_01`（1.6 × 2.0 m、破片付き） |
| 大きいモデルの形 | セルごとに面を張るとポリゴンが多すぎるので、0.4 m のグリッドに合わせた箱を組んで作る（`kizami_model.build_model_from_boxes`）。箱どうしは重ねない |
| 小物 | ベンチ、街灯、ガードレール、信号、バリケード、工事用のフェンス。ボクセルの大きさは物ごとに決めるので、グリッドと厚みの決まりは適用しない。原点と階層はこの規約に従う |
| 遠景 | 外殻エリアのビル群と外壁。プレイヤーが届かないのでボクセル化しない。グリッドと鉄筋の決まりは適用せず、シルエットだけを作る |
| 天照塔 | 既存の `Stage/big_tower.fbx` を使う。Y 40〜65 m の範囲だけをボクセル化し、強度は最大にする |

## 寸法

| 項目 | 値 |
|---|---|
| グリッド | 0.4 m。寸法と位置はすべてその倍数 |
| 厚み・隙間 | 0.8 m 以上。0.4 m のボクセルでは厚さ 0.4 m の部材が筒のように丸まる |
| 階の高さ | 4 m |
| 壁の厚さ | 内側に鉄筋を通す壁は 1.2 m（表 0.4 / 鉄筋 0.4 / 裏 0.4） |

## 形の作り方

- 0.4 m のセルの 3 次元の格子に素材を割り当て、素材ごとに、そのセルの集まりの外面を 1 つのメッシュにする。閉じたメッシュで、面は外向き
- 素材の違うメッシュは面で接するだけで、重ならない
- 壁の内側の層には `Rebar` を通す。ボクセル化で硬い部分として扱う為。表面から 0.4 m 以上内側に置き、外から見えないようにする。突き出した鉄筋だけは外に出る

## 軸・原点・階層

| 項目 | 値 |
|---|---|
| Blender での軸 | Z が上。壁の幅は X、厚さは Y |
| 書き出し | FBX。`axis_up='Y'`、`axis_forward='-Z'`、`bake_space_transform=True` で Unity の Y 上・前方 +Z にする |
| 原点 | 底面の中心（Z=0 が接地面） |
| 階層 | ルートの空オブジェクト `<モデル名>` の下に、素材ごとのメッシュ `<モデル名>_<素材>` を置く。子の原点はルートと同じ |

## 名前

- モデル名は `Stage_<区分>_<名前>_<番号>`。番号は 2 桁
- マテリアルは発注書 4.1 のスロット名（`Brick` / `Mortar` / `Concrete` / `Rebar` / `Metal` / `Wood` / `Glass`）。1 メッシュ 1 スロット

## 確認すること

- 寸法と各頂点の座標が 0.4 m の倍数
- 素材ごとのメッシュが閉じている（境界の辺がない）
- 斜め俯瞰と正面の 2 方向から Workbench で撮って形を見る
